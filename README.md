# HideMyExp
新楓之谷：經典版 隱藏經驗值


#### 使用說明

1. 啟動《新楓之谷：經典版》遊戲程式

2. 執行本程式

3. 按住滑鼠左鍵，將覆蓋視窗拖曳至目標位置

4. 滾動滑鼠滾輪調整視窗尺寸（按住 Ctrl + 滾輪可進行微調）

5. 展開桌面右下角的系統匣，對本程式圖示點擊右鍵，選擇「鎖定」即可固定視窗位置與大小


--------


橘點顏色校準：在解除鎖定的狀態下將箭頭移動至畫面上的橘色區域，建議移動至等級右下角。詳細請參考附圖。

校準後，圖像將更自然地融入畫面。


--------


#### 替換圖示：將想替換的圖示重新命名為 `image.png` 後，重新執行本程式即可


--------

#### 注意事項

- 本程式的原理為在螢幕上疊加獨立的額外視窗，不會修改遊戲主程式、遊戲資源、記憶體數據或干涉顯示卡渲染，完全不會影響遊戲本體的運作。

- 儘管本程式不包含修改遊戲的機制，但仍屬於「非官方之第三方程式」。請使用者自行評估並承擔可能遭到檢舉或帳號封鎖的風險。

- 若更改遊戲的視窗大小或解析度，請至系統匣解除鎖定後再重新調整。
